02 查找与修改 DOM

DOM（Document Object Model）是浏览器把 HTML 解析成的一棵对象树。 JS 不操作"字符串形式的 HTML"，而是操作这棵树上的对象。 本页的小节顺序和 02-dom-manipulation.js 里的一致，可以对照着看。

2. 读和写内容：textContent 与 innerHTML

下面两个框会写入完全相同的一段字符串。左边用 innerHTML， 右边用 textContent，点按钮看看差别。

innerHTML（把字符串当 HTML 解析）

textContent（把字符串当纯文本）

字符串里含有一小段 <img onerror=…>。点按钮后左边会弹出一个 alert —— 那说明这段字符串被浏览器当成真正的代码执行了。这就是 XSS（跨站脚本）的入门版： 凡是来自用户的内容（输入框、URL、接口返回），都用 textContent 写入。

3. 改样式：优先换 class，而不是直接写 style

这个盒子会被下面几个按钮折腾。

直接写 el.style.xxx 会把样式"焊死"在元素上（属于内联样式，优先级很高）， 很难被其他 CSS 规则覆盖，也不方便复用。推荐做法是切换 class，让 CSS 决定长什么样。
