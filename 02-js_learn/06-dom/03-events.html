03 事件

前两课是"页面加载后 JS 改一次"。事件让页面开始响应用户 —— 点击、输入、提交、按键，都是事件。 把输出打开（F12 / Cmd+Option+I）再操作，不然会看不懂在演示什么。

1. addEventListener 与 onclick

两个按钮上都注册了两个处理函数（都会打印日志）。 点一下就知道区别：onclick 是给属性赋值，后一个把前一个覆盖了； addEventListener 是往列表里追加监听器，两个都会执行。

表单的默认行为是"提交并刷新整个页面"。刷新一次，之前用 JS 做的一切就没了， 所以单页应用里几乎总要写 event.preventDefault()。 试试把 03-events.js 里那行 preventDefault 注释掉再提交， 地址栏会多出一个 ?name=…，页面也重新加载了。

5. 常用事件速查

在下面的日志里会出现 input / change / keydown / focus / blur / mouseenter / mouseleave 事件：
  • click / dblclick — 单击 / 双击
  • input — 输入框内容每变一次就触发（包括粘贴、删除）
  • change — 值改变且失去焦点时触发（下拉框选完就触发）
  • submit — 表单提交（绑在 <form> 上，不是按钮上）
  • keydown / keyup — 键盘按下 / 松开
  • mouseenter / mouseleave — 进入 / 离开（不冒泡）
  • focus / blur — 获得 / 失去焦点
  • DOMContentLoaded — DOM 解析完成（defer 脚本其实不用等它）

6. 取消监听与阻止冒泡

取消监听要用 同一个函数引用： el.addEventListener("click", fn) 之后， 必须用 el.removeEventListener("click", fn)， 传一个新的箭头函数是删不掉的 —— 这点和 C 里"传函数指针"是一样的道理。 另外 event.stopPropagation() 可以阻止事件冒泡， 但它会让祖先元素收不到事件，通常有更好的解法（比如第 3 节的事件委托），能不用就不用。
