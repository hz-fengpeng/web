# 03 练习

练习时先独立完成，再对照 `examples/profile-card`。每一题都应在浏览器开发者工具中检查一次窄屏效果和盒模型。

## 练习 1：修改综合示例

打开 `examples/profile-card/index.html`，完成以下修改：

1. 把姓名、介绍和技能换成你自己的内容。
2. 增加一个新的技能标签。
3. 修改 CSS 自定义属性，形成另一套配色。
4. 把桌面端的两栏比例从 `3fr 2fr` 改成 `2fr 1fr`，观察差异。
5. 临时删除 `.profile__details { min-width: 0; }`，输入一串很长的英文，观察溢出后再恢复。

验收：页面在 320px 宽度下不出现横向滚动，键盘 Tab 可以清楚地看到焦点位置。

## 练习 2：课程表

从空白文件创建一个课程表页面，至少包含：

- 页面标题和一段介绍。
- 一个包含表头、表体和标题的 `table`。
- 至少 5 行课程数据。
- 隔行背景色和表头样式。
- 表格在窄屏下可以横向滚动，而不是撑破整个页面。

重点：使用表格语义，不用一堆 `div` 模拟单元格。

## 练习 3：注册表单

创建包含姓名、邮箱、学习方向、个人介绍和协议勾选框的注册表单。

验收要求：

- 每个控件都有可见的 `label`。
- 邮箱使用 `type="email"`，必填项使用 `required`。
- 表单控件在 focus 时有明显轮廓。
- 桌面端姓名和邮箱并排，移动端改为单列。
- 提交按钮使用真正的 `button`。

## 练习 4：响应式文章列表

创建至少 6 张文章卡片，每张包含分类、标题、摘要、日期和链接。

- 小屏幕为 1 列。
- 中等屏幕为 2 列。
- 宽屏为 3 列。
- 每行卡片高度随内容自然变化，文字不能互相覆盖。
- 卡片链接需要 hover 和 `focus-visible` 状态。

尝试分别用明确的媒体查询，以及 `auto-fit + minmax()` 两种方式实现并比较。

## 练习 5：不看资料复刻

任选一个结构清晰的网页区域，只复刻其中一屏。先在纸上或注释中拆分：

```text
页面
├── header
│   ├── logo
│   └── nav
└── main
    ├── intro
    └── card-list
        └── card × N
```

先写 HTML 确保内容顺序合理，再添加 CSS。不要一开始就处理颜色和阴影。

## 完成后的检查清单

- HTML 是否有唯一、准确的 `title` 和 `h1`？
- 标题层级是否连续？
- 链接用于导航、按钮用于操作吗？
- 表单是否有 label，图片是否有 alt？
- 是否出现重复 id？
- 是否能解释每个 `div` 为什么存在？
- 是否大量依赖固定宽高或 absolute 定位？
- 320px、768px 和 1280px 宽度下是否都可读？
- 键盘能否操作所有交互元素并看见焦点？
- 开发者工具 Console 是否有资源加载错误？
