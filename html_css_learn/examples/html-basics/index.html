HTML 描述内容的含义

HTML 不只是把文字放进页面，它还告诉浏览器这些内容是什么。 例如，标题表达层级，强调元素表达语气， 链接则把当前页面与其他资源连接起来。

你可以继续查看 个人资料页综合示例， 或在 MDN HTML 文档 中查询标签的完整用法。

编写页面的三个步骤

  1. 根据内容含义选择合适的标签。
  2. 检查嵌套关系与标题层级。
  3. 在浏览器中验证链接、表单和键盘操作。

常用内容元素

  • h1 到 h6：标题层级
  • p：独立的文字段落
  • ul、ol 和 li：列表
  • a：前往其他地址或页面位置
