# 可视化设计规范与页面设计

> 本文档是《开发文档》的 §6–§7 部分；全部文档见 [docs/README.md](README.md)。

## 6. 可视化设计规范

> ⚠️ **本节是规范性规范**——源码注释以 `§6.x` 引用它来约束图表的画法。
>
当前提供单指标折线图、同口径对比折线图，以及统计卡片与 KPI 行。

### 6.1 形式选择

- 最新值使用统计卡片，分别写明各指标期间与口径；变动为相邻可比期间的计算值。
- 时间趋势使用真实时间轴折线，缺失值断线，合并发布用菱形点与文字说明。
- 对比只允许同口径、单位、频率及季调状态的 1–3 个指标，共用一根 y 轴，不插值。
- 不同口径使用概览的独立图，不使用双轴图。

### 6.2 配色系统

#### 序列色

所有折线仍使用同一个 `--c-accent`：浅色 `#2a78d6` / 深色 `#3987e5`。
单序列不需要图例；对比页通过外置文字图例及三种线型/点形编码区分序列：

| 对比位置 | 线型 | 点形 |
|---|---|---|
| 1 | 实线 | 圆 |
| 2 | 虚线 | 方 |
| 3 | 点线 | 三角 |

合并发布的观测统一改为菱形，并写明真实期间与合并状态。
PNG 中保留各序列的线型说明。当前没有新增色相，区分不依赖色觉；
以后增加序列颜色时仍需单独做正常视觉与 CVD 校验，不能循环色板。

#### 状态色（固定，不随主题变化）

| 用途 | 色值 | 浅色表面对比度 | 深色表面对比度 |
|---|---|---|---|
| good | `#0ca30c` | 3.27 | 5.19 |
| warning | `#fab219` | 1.79 | 9.49 |
| serious | `#ec835a` | 2.57 | 6.60 |
| critical | `#d03b3b` | 4.68 | 3.62 |

**状态色永远搭配图标 + 文字标签**，绝不单靠颜色传达状态——`App.tsx` 的 `HealthDot` 就是这个
形状：`● 正常` / `◐ 部分指标失败` / `▲ 采集失败` / `○ 未采集`，颜色只是第三条通道。
浅色模式下 warning 和 serious 天然低于 3:1，图标 + 标签就是这个设计的补偿手段。

#### 框架与文字色

| 角色 | 令牌 | 浅色 | 深色 |
|---|---|---|---|
| 页面底板 | `--c-canvas` | `#f9f9f7` | `#0d0d0d` |
| 图表表面 | `--c-surface` | `#fcfcfb` | `#1a1a19` |
| 主要文字 | `--c-ink` | `#0b0b0b` | `#ffffff` |
| 次要文字 | `--c-ink-2` | `#52514e` | `#c3c2b7` |
| 弱化（坐标轴/刻度） | `--c-ink-muted` | `#898781` | `#898781` |
| 网格线（hairline） | `--c-grid` | `#e1e0d9` | `#2c2c2a` |
| 基线 / 坐标轴 | `--c-axis` | `#c3c2b7` | `#383835` |
| 边框 | `--c-hairline` | `rgba(11,11,11,.10)` | `rgba(255,255,255,.10)` |

> **文字永远穿文字色，不穿序列色。** 数值、标签、图例一律用上表的文字色；身份由旁边的色块承载。

### 6.3 涨跌配色决策（本产品的特殊问题）

中国金融惯例是**红涨绿跌**，与欧美完全相反。但红绿恰恰是色觉障碍（红绿色盲，人群中约 8% 的男性）最难区分的一对。

**处理方案：**

1. **默认遵循中文用户习惯：红涨绿跌。**（目前设置页只提供主题与默认时间窗，尚不提供涨跌配色切换）
2. **无论选哪种，涨跌必须三重编码：数值 + 符号/箭头（▲▼）+ 颜色。** 颜色绝不单独承载涨跌含义。
3. 涨跌色**不占用分类色槽位**——它是独立的一组语义色，不参与 6.2 的序列色序。
4. 表格视图中，涨跌列始终带 `+` / `−` 符号。

| 令牌 | 浅色 | 深色 |
|---|---|---|
| `--c-up`（涨） | `#d03b3b` | `#e66767` |
| `--c-down`（跌） | `#0ca30c` | `#0ca30c` |

> 这是本产品在无障碍与本地习惯之间的关键权衡。遵循本地习惯是必要的（否则用户会读反），但必须用符号和数值兜底，让色觉障碍用户同样能准确读取。

### 6.4 图表规范（marks）

- **线宽 2px**；数据点标记直径 **≥ 8px**
- **重叠的 mark**：加 **2px 表面色描边环**（`--c-surface`——交叠处才分得开）
- **网格线**：hairline，弱化处理；**不要垂直网格线**（时间序列的 x 轴网格通常是噪音）
- **坐标轴**：只保留基线，不要边框盒子
- **标注**：**选择性直接标注**关键点，不要每个点都标数字
- **图例**：≥ 2 个序列**必须**有图例；≤ 4 个序列同时做直接标注；**单序列不要图例框**（标题已经说明了它是什么）
- **字体**：全程系统无衬线，不使用装饰性字体。**字体栈的事实源是 `styles/index.css` 的 `--font-sans`**，不要在这里再抄一份（本节原先抄的那串就与代码不符：多了 `system-ui` / `Segoe UI`，少了 `BlinkMacSystemFont` / `Helvetica Neue`）。坐标轴与图例是 canvas 画的、不会从 DOM 继承字体，必须显式传给它（`charts/theme.ts` 的 `sans` 字段）。
- **数字**：hero 数字与表格各列**用等宽数字**（`tabular-nums`，即 `styles/index.css` 的 `.tnum`）——数值会随选中指标变化，比例数字会让整块布局左右跳动。⚠️ **坐标轴刻度做不到这件事**：`.tnum` 是 DOM 的 `font-variant-numeric`，而刻度是 ECharts 在 canvas 上画的文字，不继承 DOM 字体特性，全仓也没有对应的 ECharts 设置。这条目前只对 hero 与表格成立。

### 6.5 交互规范

- **折线图默认带十字准星 + tooltip**（这是默认，不是可选）
- **命中区域要比 mark 本身大**（细线尤其需要）
- **数据表视图**：每个图都应能切换到「看数据」模式——这是无障碍硬要求（`components/UI.tsx` 的
  `ViewToggle`）。逐期数值、发布日与修订状态**不一定只能在这里读到**：十字准星的 tooltip
  同样输出这四样（`lineOption.ts` 的 `formatter`）。数据表是其中**唯一不依赖鼠标悬停**的
  通道，这才是它不可省的理由

### 6.6 反模式清单

- ❌ **双轴图**（两种量纲共用一张图）——宏观经济图表最常见的错误："把 CPI 和 M2 放一张图"。
  两个 y 轴之间没有任何可解释的关系，读者会看到虚假的相关性。正确做法：两个图、小倍数、
  或指数化到同一基期。（这条原在 §6.1，该节删除时唯一保留下来的规则）
- ❌ **彩虹色 / 循环使用色相**——序列再多也**不生成新色相**，到上限就折叠为「其他」或改用分面（§6.2 的「固定顺序，按序分配，绝不循环」）
- ❌ **颜色跟随排名而非实体**——筛选后幸存序列不得换色
- ❌ **用颜色单独表达状态或涨跌**（必须有图标 + 文字）
- ❌ 每个数据点都标数值——选择性直接标注关键点
- ❌ 3D 效果、阴影、渐变填充

### 6.7 深浅色模式

- 深浅色**各自独立取阶**，不是自动反转
- 深色模式的值必须**针对深色表面重新验证**——`index.css` 的
  `@media (prefers-color-scheme: dark)` 里那套就是验证过的深色色值，不是把浅色值调暗得来的
- **跟随系统已实现**（`styles/index.css` 的 `prefers-color-scheme`）。**手动切换已实现**：设置页选择浅色/深色/跟随系统，保存在本机；`data-theme` 的手动选择优先于系统，图表监听属性变化重新读取令牌
- 在 `styles/index.css` 里用 `@theme inline` 统一定义 CSS 变量，图表主题与 UI 共用同一套令牌

## 7. 页面设计

### 7.1 页面结构

`App.tsx` 管理本地导航与读库状态，页面组件在 `pages/` 中，无额外路由依赖。
窗口顶部的示例声明和底部的离线状态在所有页面常驻。

| 页面 | 已实现行为 |
|---|---|
| 经济概览 | 12 个核心 KPI / 我的关注，6 张 GDP、CPI、PMI、社零、M2、社融趋势图，可切换数据表，点击进入详情 |
| 指标库 | 分类、P0/P1/P2 筛选、名称/口径/ID/地区搜索、排序、关注、每页 24 个指标 |
| 对比分析 | 1–3 个可比指标，搜索/层级筛选，真实时间轴、线型/点形图例、时间窗、对齐表格、CSV / PNG |
| 发布日历 | 月份导航、分类/日期筛选、发布记录表、跳转详情；保留历史修订的发布事件 |
| 数据管理 | 指标/记录数量、来源状态、逐指标覆盖与缺失情况、全部 CSV（含修订）、重置确认 |
| 设置 | 系统/浅色/深色、默认时间窗、偏好本地保存、关于说明 |

日历的日期来自示例库 `releasedAt`，不代表官方安排，也不推测未来日期。
默认打开库内最近有发布记录的月份，避免固定旧库按系统日期打开成空白。

### 7.3 指标详情页（Detail）

- 标题、最新观测值、期间、示例发布日、观测状态和相邻可比期间的变动。
- 常驻口径说明、口径/频率/季调标签；工业增加值可切换同比/环比，切换后重新画独立图。
- 近 1/3/5 年、全部、自定义期末日期范围；快捷范围锚定该序列最新期末，不依赖系统日期。
- 图表 / 数据表切换。表格每页 24 条，范围变化自动回到第一页。
- 单期多个修订默认取最高 revision（即使其值为 null 也不回退旧值）；历史修订展开可读。
- 当前范围导出 CSV、图表导出 PNG。CSV 附带 BOM、单位、口径、状态、发布日、修订号与口径说明。
  PNG 附带标题、范围、口径说明及“示例数据，非真实统计”；导出前固定动画最终帧。
- 缺期、缺值、1—2 月合并相关期间不计算变动，累计口径跨年也不计算。百分数的差用“个百分点”，
  不称为同比/环比增速；这是计算值而非新增原始统计。
- 关注可在详情与指标库操作，保存在本机，并同步到概览关注视图。

### 7.4 状态与可访问性

初次读取有加载状态，读取失败有错误横幅与重试；后续失败保留已有数据快照。
空筛选、空范围和日期颠倒都有说明。`ErrorBoundary` 提供渲染失败后的重新加载入口。

所有操作控件使用原生按钮、输入、选择框；当前页面、切换状态与关注状态都有语义属性。
提供跳到主内容链接、页面标题焦点、可见焦点环、原生 modal 的焦点约束和 Escape 取消。
图表均有文字描述及数据表替代，主题与 UI 共用 CSS 令牌。

完整屏幕阅读器验收、性能基准与 Electron 原生对话框实机验收仍待执行。

### 7.5 扩充指标后的显示约束

层级、地区和“示例计算值”标签同时用于详情、指标库和 CSV。
日度汇率展示四位小数，LPR/收益率两位小数，变动量沿用指标精度；超过 90 个点的日度图
只画折线并在悬停时展示点，避免数百个圆点盖住趋势。日度轴标签包含年份，跨年不会产生歧义。

所有 PMI 系列有 50 荣枯线。省级 GDP 为季度累计同比，只与相同频率/口径比较，
不能与全国 GDP 当季同比叠图。LPR 的月度期末用于对齐，详情仍显示当月真实模拟报价日。
默认时间窗始终锚定库内最新期末，年度指标不会被当前系统日期错误截空。
