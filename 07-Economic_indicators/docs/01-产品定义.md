# 产品定义

> 本文档是《开发文档》的 §1–§2 部分；全部文档见 [docs/README.md](README.md)。

## 1. 项目概述

### 1.1 一句话定位

一个完全离线的桌面应用，把**按官方口径定义**的宏观经济指标集中到一个可交互、口径可追溯的看板里。

> 两个措辞是有意的：「完全离线」是因为应用根本不联网（§5.1），不是「联网为主、离线兜底」；
> 「按官方口径定义」是因为**库里的数值是合成的**（§3.2.0）——真实的是各指标的统计口径，
> 不是数字。本句原先写「中国官方发布的宏观经济指标」，与本项目自己的横幅声明直接矛盾；
> 同一句里的「可导出」也已删除，导出尚未实现（§1.3）。

### 1.2 目标用户与核心场景

| 用户 | 核心场景 |
|---|---|
| 投研 / 分析师 | 快速查一个指标的长历史序列，看口径与修订状态 |
| 企业战略 / 市场 | 每月数据发布后，一眼看清关键指标的最新值与边际变化 |
| 学生 / 研究者 | 需要权威、带口径说明、可溯源的数据，不要二手加工过的数字 |
| 个人投资者 | 跟踪货币、社融、PMI 等先导指标的变化方向 |

### 1.3 设计目标

- **口径清晰**：同比 / 环比 / 累计同比 / 单月值严格区分，绝不混在一张图里。这是同类工具最常见的错误。
- **口径可追溯**：每个指标常驻展示口径说明与单位，不藏进 tooltip——这是本产品相对同类工具的核心差异化。
- **快**：本地 SQLite。切换指标 < 100ms；**没有「等待初始化」这个状态**，数据在开窗之前就到位了。
- **单一技术栈**：全链路 Node / TypeScript，不引入 Python，不设构建期的数据管线。
- **离线**：应用根本不联网（§5.1），离线可用是默认状态，不是降级状态。
- **不骗人**：★ 显示的每个数字，其真伪状态必须与界面声明一致——库里是合成的演示数据，界面就必须明说（§3.2.0）。

> **尚未实现，属于路线图**：图表导出 PNG、数据导出 CSV（§7.3）；接入真实官方数据源（§13 决策 3、10）。
> 本节原先还写着「权威：只采信官方发布源，每个数字能点回源头」「首次启动优先拉取近 3 年数据，
> 完整历史在后台补全」——采集层已整体移除，这两条不再是目标形态。

### 1.4 非目标（明确不做）

- ❌ 不做实时行情 / 股票 / 期货（这是宏观数据工具，不是行情终端）
- ❌ 不做预测和模型（只呈现已发布的事实数据）
- ❌ 不做数据二次加工后当作原始值展示（可以有衍生计算，但必须显著标注"计算值"）
- ❌ MVP 不做多用户、云同步、账号体系
- ❌ 不内置任何付费终端（Wind / iFinD / Choice）的数据
- ❌ **不对外分发**——个人自用工具。因此不做代码签名、公证、自动更新、上架，也不考虑他人环境下的兼容性与首次运行体验

## 2. 指标范围

**已实现 10 个指标**，定义在 `src/shared/indicators.ts`——那是**指标元数据的唯一事实源**，
UI 与测试都从它读取，不存在第二处定义。

**本文档不再维护平行的指标清单。** 本节原先那张表列了 25 个指标、5 个数据源、以及各源的接入
顺序，而实际实现的是 10 个、数据是内置的合成库（§3.2.0）——表格与代码一分叉就再没对上过。
所以这里只记分类与取舍，具体指标以代码为准。

已实现的 10 个，按界面里的分类：

| 分类 | 指标 |
|---|---|
| 经济增长 | GDP 当季同比；规模以上工业增加值 当月同比 / 当月环比 |
| 物价 | CPI 当月同比；PPI 当月同比 |
| 景气调查 | 制造业 PMI |
| 内需 | 社会消费品零售总额 累计同比；固定资产投资 累计同比；房地产开发投资 累计同比 |
| 就业 | 全国城镇调查失业率 |

（分类中文名取自 `lib/format.ts` 的 `CATEGORY_LABEL`，指标定义取自 `indicators.ts`。
这张表只是给人看的导航，**仍然以代码为准**。）

### P0 · MVP 核心指标

已实现 10 个（见上表）。原 P0 清单里**尚未实现**的部分：

- 核心 CPI 同比
- 非制造业 PMI
- 出口金额 当月同比（美元）、贸易差额（美元）
- M1 同比 / M2 同比、社会融资规模存量 同比、新增人民币贷款 当月值、LPR 1 年期 / 5 年期以上
- 外汇储备、美元兑人民币 中间价
- 一般公共预算收入 累计同比

> ⚠️ **重新接入真实数据源时**，顺序仍是 **国家统计局 → 人民银行 → 海关总署 → 外汇管理局 → 财政部**
> （§13 决策 3）。需要注意：**NBS 单独并不构成可用产品——M2、社会融资规模是中文宏观分析中最受
> 关注的月度指标**，缺少它们，概览页 KPI 行会缺掉最核心的一块。因此 NBS 先行只是**工程上的降风险
> 手段**，人民银行必须紧随其后。
