# 产品定义

> 本文档是《开发文档》的 §1–§2 部分；全部文档见 [docs/README.md](README.md)。

## 1. 项目概述

### 1.1 一句话定位

一个完全离线的桌面应用，把**按官方口径定义**的宏观经济指标集中到一个可交互、可导出、口径可追溯的看板里。

> 两个措辞是有意的：「完全离线」是因为应用根本不联网（§5.1），不是「联网为主、离线兜底」；
> 「按官方口径定义」说的是**每个指标的统计口径**——谁发布的、什么范围、哪个是累计、
> 哪个要季调。口径定义与「数字是真是假」是两件事：口径靠 `indicators.ts` 的 `note` 声明，
> 数值则**只能是抓来的或留空的**——每条有值的观测都得能在 `fetch_log` 里找到采集记录
>（§3.2.7、§14.4）。本句原先写「中国官方发布的宏观经济指标」，在库里还是合成数据的
> 那段时间与本项目自己的横幅声明直接矛盾，所以改成现在这个说法。
> CSV / PNG 导出已实现，文件带数据来源声明（§7.3）。

### 1.2 目标用户与核心场景

| 用户 | 核心场景 |
|---|---|
| 投研 / 分析师 | 快速查一个指标的长历史序列，看口径与修订状态 |
| 企业战略 / 市场 | 每月数据发布后，一眼看清关键指标的最新值与边际变化 |
| 学生 / 研究者 | 需要权威、带口径说明、可溯源的数据，不要二手加工过的数字 |
| 个人投资者 | 跟踪货币、社融、PMI 等先导指标的变化方向 |

### 1.3 设计目标

- **口径清晰**：同比 / 环比 / 累计同比 / 单月值严格区分，绝不混在一张图里。这是同类工具最常见的错误。
- **口径可追溯**：每个指标常驻展示口径说明与单位，不藏进 tooltip——这是本产品相对同类工具的核心差异化。
- **快**：本地 SQLite。切换指标 < 100ms；**没有「等待初始化」这个状态**，数据在开窗之前就到位了。
- **单一技术栈**：应用全链路 Node / TypeScript。采集是**应用外**的开发期工具
  （[`fetcher/`](../fetcher/README.md)，Python + akshare），不进构建期管线、不进 IPC、
  不进安装包——`npm run build` 不抓数，库是提交进仓库的。
- **离线**：应用根本不联网（§5.1），离线可用是默认状态，不是降级状态。
- **不骗人**：★ 显示的每个数字，要么是抓来的、要么留空，没有第三条来路——判据是
  「有值的观测都能在 `fetch_log` 里找到采集记录」（§3.2.7、§14.4），界面报出处与推算边界。

> **已实现**：图表导出 PNG、数据导出 CSV（§7.3）、P0 的真实数据接入（§14）。
> **尚未实现**：P1/P2 的数据源（库里没有观测，界面显示「暂无数据」）、官方发布时刻
> （`released_at` 是按惯例推算的，§14.6）、付费终端数据。
> 本节原先写着「权威：只采信官方发布源，每个数字能点回源头」——数现在确实来自官方公开渠道，
> 但**「点回源头」这条没做到**：库里不存上游链接，akshare 只是取数通道。

### 1.4 非目标（明确不做）

- ❌ 不做实时行情 / 股票 / 期货（这是宏观数据工具，不是行情终端）
- ❌ 不做预测和模型（只呈现已发布的事实数据）
- ❌ 不做数据二次加工后当作原始值展示（可以有衍生计算，但必须显著标注"计算值"）
- ❌ MVP 不做多用户、云同步、账号体系
- ❌ 不内置任何付费终端（Wind / iFinD / Choice）的数据
- ❌ **不对外分发**——个人自用工具。因此不做代码签名、公证、自动更新、上架，也不考虑他人环境下的兼容性与首次运行体验

## 2. 指标范围

**已定义 109 个指标**（口径、单位、频率与层级），统一由 `src/shared/indicators.ts` 的 `INDICATORS` 导出。
初始指标与新增 P0 定义在该文件，P1/P2 定义分文件组织在 `expandedIndicators.ts`。
**定义不等于有数据**：随包发布的库里只有 P0 的 23 个有观测（其中 18 个有值），
其余指标界面显示「暂无数据」——覆盖范围见 [§14](08-真实数据采集.md) 与 [fetcher/README.md](../fetcher/README.md)。

| 层级 | 指标数 | 覆盖内容 |
|---|---:|---|
| P0 | 23 | 原有增长/物价/景气/内需/就业，新增核心 CPI、非制造业 PMI、外贸、M1/M2/社融/贷款/LPR、外储汇率、财政收入 |
| P1 | 38 | 制造业与基建投资、5 类社零、5 个贸易伙伴的进出口、财新 PMI、服务业、发电/用电、居民收入支出、基金/土地收入、GDP 平减指数、国债收益率与中美利差及计算输入 |
| P2 | 48 | 年度人口/城镇化率/基尼系数、国际收支主要账户和分项、外债、31 个省级 GDP 累计同比、克强指数（加权增速） |

数据覆盖日度、月度、季度、年度序列；省级 GDP 是**累计同比**，与全国 GDP 当季同比保持分开。
国别贸易与社零类别是选定的分类，不构成所有国别或所有商品的完整全集；国际收支提供主要账户及分项，
金融账户使用资产净获得减负债净发生方向，其与经常、资本账户的平衡关系见口径说明。

**P1/P2 全部、以及 P0 里那 5 个没有免费源的指标，库里没有观测**——不是合成值，是留空，
界面显示「暂无数据」；每条留空的理由写在 [`mapping.py`](../fetcher/macro_fetcher/mapping.py)
的 `UNSOURCED` 里，没有理由的空白不算数（§14.2）。中美利差、GDP 平减指数、克强指数、
国际收支账户合计/平衡项是**计算值**，接入时须显著标注，目前均未接入。

扩大覆盖时仍按国家统计局 → 人民银行 → 海关总署 → 外汇管理局 → 财政部推进；
本轮实际先走通的是东财（月度覆盖最全）、统计局与外汇局三个通道，见 §14。
